================================================================================
FILE LINKING (Important!)
================================================================================

The three main files are CONNECTED:

index.html links to style.css:
  <link rel="stylesheet" href="style.css">

index.html links to script.js:
  <script src="script.js"></script>

If they're in different folders, the links break!

CORRECT:
  kaleemullah-portfolio/
  ├── index.html
  ├── style.css
  └── script.js
  
  (All in same folder)

WRONG:
  kaleemullah-portfolio/
  ├── index.html
  ├── css/style.css      ← Wrong folder!
  └── js/script.js       ← Wrong folder!
  
  (If you do this, links need to be: href="css/style.css")

================================================================================
BEFORE YOU PUSH TO GITHUB
================================================================================

1. SETUP (one time):
   - Open Terminal/Command Prompt in kaleemullah-portfolio folder
   - Run: git init
   - Run: git config --global user.name "Your Name"
   - Run: git config --global user.email "your-email@gmail.com"

2. ADD & COMMIT:
   - Run: git add .
   - Run: git commit -m "Initial portfolio commit"

3. CONNECT TO GITHUB:
   - Create repository on GitHub (same name)
   - Run the commands GitHub gives you

4. ENABLE GITHUB PAGES:
   - Settings → Pages
   - Select "main" branch
   - Save

5. YOUR SITE IS LIVE:
   - https://YOUR-USERNAME.github.io/kaleemullah-portfolio/
