## 🎨 Design Specifications

### Color Scheme (Professional Dark)
- Primary: `#00d4ff` (Cyan - cybersecurity themed)
- Background Dark: `#0a0e27` (Deep navy)
- Background Darker: `#050812` (Almost black)
- Text Primary: `#e0e6ff` (Light blue-white)
- Text Secondary: `#a0aac3` (Muted gray-blue)
- Border: `#1f2937` (Subtle gray)
- Accent: `#6366f1` (Indigo)
- Success: `#10b981` (Green)

### Typography
- Main Font: System fonts (Apple/Helvetica/Segoe UI/Roboto)
- Monospace: Courier New
- Font Sizes: Responsive (clamp() for scalability)
- Font Weights: 600-800 for headings, 400-600 for body

### Spacing
- Consistent 8-unit grid system
- Variables: xs (0.5rem), sm (1rem), md (1.5rem), lg (2rem), xl (3rem), 2xl (4rem)

### Responsive Breakpoints
- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px
- Extra small: 480px for phones

### Animations & Effects
- Fade-in on scroll (smooth, 0.6s)
- Card hover: translate 4-6px up + shadow
- Button hover: slight scale and shadow increase
- Link underline: smooth width animation
- Smooth scroll navigation
- Respect prefers-reduced-motion (accessibility)
